# AI UI Instructions

Before making any ASDM UI change:

1. Read `docs/DESIGN-SYSTEM.md`.
2. Inspect existing components, tokens, and route structure.
3. Reuse `src/styles/tokens/` and `src/components/ui/` before adding new styles.
4. Do not invent brand colours, typography, layouts, or ASDM claims.
5. Keep red restrained and reserved for primary actions, focus, selected states, and important links.
6. Use the shared container/grid so header, hero, and sections align.
7. Use only approved local assets from `public/assets/`.
8. Preserve SEO URLs unless an approved migration entry exists.
9. Validate desktop and mobile behaviour, accessibility, and overflow.
10. Update `docs/TASKS.md` and `CHANGELOG.md` for completed UI work.
