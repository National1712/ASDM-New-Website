## Design-System Budgets

- Client JavaScript for global shell: target under `8 KB` uncompressed per route.
- CSS generated by design-system route: target under `32 KB` uncompressed before minification.
- Fonts: no remote production font requests. Use system fallback now; add self-hosted WOFF2 only after license and byte-size review.
- Images: local assets only, explicit dimensions or stable aspect-ratio wrappers.
- Motion: CSS transitions and small native scripts only. No animation dependency.
- Frameworks: Astro only for Phase 6 primitives.
