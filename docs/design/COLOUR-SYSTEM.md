# Colour System

Status: `PHASE 6.2 RED-LED SYSTEM APPROVED`
Last updated: 2026-08-01

## Owner Decision

- Red is the primary ASDM brand and action colour.
- Purple is a controlled secondary accent.
- Blue is not the main brand, action, focus, link, tab, or CTA colour.
- Black and charcoal support typography and selected inverse surfaces.
- Warm orange is used sparingly.

## Palette Philosophy

The ASDM palette is neutral-dominant with red reserved for action and focus. Purple adds identity depth in support roles. The system avoids red overload by keeping most surfaces, cards, typography, and borders neutral.

## Semantic Status Tokens

- Success: `#167a3f`
- Warning: `#9a6500`
- Error: `#c3212d`
- Information: `#3a6f86`

Information remains semantic and muted so it does not compete with ASDM red.

## Gradient

Restrained brand gradient:

`linear-gradient(135deg, #e1262f 0%, #d92745 45%, #65429b 100%)`

Use this only for controlled showcase or approved storytelling moments, never behind long-form text without contrast verification.
