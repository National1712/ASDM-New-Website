# Colour Visual QA

Status: `PHASE 6.2 QA RECORDED`
Last updated: 2026-08-01

## Checks

- Primary buttons use red tokens, not blue.
- Text links use red hover and active color behavior.
- Tabs use red selected states.
- Focus ring uses red and remains visible on light and dark surfaces.
- Purple appears only as a secondary badge/button/accent option.
- Orange is limited to warm accent tokens and small supporting use.
- Neutral surfaces remain dominant across the design-system page, header, and footer.
- Information color is muted and semantic, not an action blue.
- Dark surfaces use deep charcoal, readable inverse text, and red/purple accents sparingly.
