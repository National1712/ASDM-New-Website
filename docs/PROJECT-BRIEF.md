# Project Brief: ASDM Website Redesign

This document outlines the high-level business objectives, design inspiration reference sites, technical direction, and constraints for the Ahmedabad School of Digital Marketing (ASDM) website redesign.

## 📈 Project Status

- **Status**: `APPROVED`
- **Last Updated**: 2026-08-01

---

## 🎯 Project Goal

Build a premium, highly-customised, high-performance website for ASDM. The final site must feel professionally designed by an experienced digital product team, rather than a generic template generated by AI.

## ⚙️ Technical Constraints

- **Framework**: Astro (v5) - Static Site Generation by default.
- **Language**: Strict TypeScript.
- **CSS**: Scoped CSS or Governed Tailwind (to be defined in the design system phase).
- **Hosting**: Static edge hosting (Vercel, Netlify, or Cloudflare Pages).
- **Core Web Vitals Targets**:
  - Mobile Lighthouse Performance: 90+
  - Desktop Lighthouse Performance: 95+
  - LCP: < 1.8s
  - CLS: < 0.05
  - INP: < 150ms
  - Accessibility: WCAG 2.2 AA compliant.

## ⚠️ Assumptions & Risks

### Assumptions

- ASDM course offering details, locations, and curricula are mapped. We must obtain administrative approval to reconcile the statistical discrepancies before visual execution.
- Target audience is local students, working professionals, and businesses in Ahmedabad, Surat, and Mumbai (Online).
- Design-system planning and setup (Phase 4) may proceed with unresolved claims, provided disputed claims remain excluded from production code or are clearly marked as pending verification.
- Research-driven layout architecture follows strict visual safeguards; distinctive layouts, illustration assets, motion files, or copywriting must not be directly copied from education competitors or premium reference sites (ADR-006).
- All competitor research findings must be rigorously mapped to verified evidence, separating observations from recommendations, and treating competitor patterns as conversion hypotheses (ADR-007).
- Experience and information architecture must be locked before visual design system or styling rules are initiated, ensuring design choices support verified user/business needs (ADR-008).

### Risks

- **Content & Stat Bloat**: Large page sizes due to excessive marketing text and duplicate cloned layouts. Mitigated by redirecting duplicate URLs and consolidation.
- **Statistic Mismatch / Credibility Risk**: Public conflicts between 200k vs 50k students and 50k vs 7k placements. Mitigated by enforcing a strict Truth-in-Advertising guideline and requiring administrator sign-off.
- **Mumbai Campus Discrepancy**: Mumbai lacks physical campus details despite claiming offline courses. Mitigated by labeling Mumbai as online-only or flagging for branch details.
- **SEO Degradation**: Old URLs might break if redirects are not mapped. Mitigated by implementing the SEO Migration redirect map.
