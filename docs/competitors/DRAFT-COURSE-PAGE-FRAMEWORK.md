# Draft Course Page Framework (DRAFT-COURSE-PAGE-FRAMEWORK.md)

This document outlines the proposed layout framework for program-specific detail pages (e.g. AI Integrated Advanced Digital Marketing, E-Commerce Marketing, Advanced SEO).

---

## 📐 Course Page Section Sequence

### 1. Program Hero (Value Proposition)

- **Evidence IDs**: `EVI-IIDE-HUB`, `EVI-TOPS-AMD`
- **ASDM-Specific Business Reason**: Establish the course name, duration, and co-branded NSDC credentials as soon as a user clicks into a course details page.
- **Content Dependency**: Course duration and mode options.
- **Asset Dependency**: Course program icon SVG.
- **SEO Purpose**: Primary anchor for course keyword target (e.g. `ecommerce course in ahmedabad`).
- **Conversion Hypothesis**: Adding co-branded NSDC credential badges near the hero title improves syllabus download rate.
- **Testing Requirement**: Run visual regression checks on multiple devices.
- **Originality Safeguard**: Use standard clean layout. Do not copy IIDE neon buttons or orange outlines.

---

### 2. Parameters Grid (Quick Facts)

- **Evidence IDs**: `EVI-IIDE-HUB`
- **ASDM-Specific Business Reason**: Clearly list class parameters (times, durations, batch sizes) to help prospective students verify schedule fit.
- **Content Dependency**: Confirmed batch calendar dates.
- **Asset Dependency**: None.
- **SEO Purpose**: High keyword search match for local training.
- **Conversion Hypothesis**: Transparently listing batch start dates cuts down bounce rates.
- **Testing Requirement**: Text legibility audit on mobile viewports.
- **Originality Safeguard**: Use uniform border grids. Do not use colorful card panels.

---

### 3. Curriculum Syllabus Accordion

- **Evidence IDs**: `EVI-IIDE-HUB`
- **ASDM-Specific Business Reason**: Provide complete topical breakdown of learning modules, from SEO to AI marketing tools.
- **Content Dependency**: Locked course curriculum modules.
- **Asset Dependency**: None.
- **SEO Purpose**: Search indexing of technical course modules (e.g., PPC, Google Ads).
- **Conversion Hypothesis**: Interactive expand/collapse accordions keep content digestible.
- **Testing Requirement**: Minimum tap target of 48px for each collapsible header.
- **Originality Safeguard**: Muted grey dividers. Do not copy IIDE color swatches.

---

### 4. Mastered Tools Mapped

- **Evidence IDs**: `EVI-IIDE-HUB`
- **ASDM-Specific Business Reason**: Visually show the software tools (e.g., Shopify, WordPress, Google Ads) students will gain expertise in.
- **Content Dependency**: List of software modules.
- **Asset Dependency**: Clean vector tool logos from `public/assets/tools-logo/`.
- **SEO Purpose**: Ranks for searches matching tool-specific training (e.g., "Shopify training Ahmedabad").
- **Conversion Hypothesis**: Seeing well-known software logos builds high practical skill expectation.
- **Testing Requirement**: Enforce width/height boundaries on SVG nodes to prevent CLS.
- **Originality Safeguard**: Grid alignment with monochrome filters on hover.

---

### 5. Practical Projects (Hands-on Lab)

- **Evidence IDs**: `EVI-IIDE-HUB`
- **ASDM-Specific Business Reason**: Concrete proof of live client budget campaigns.
- **Content Dependency**: Verified student campaign results.
- **Asset Dependency**: Screenshots of real campaign dashboards.
- **SEO Purpose**: Unique local page content relevance.
- **Conversion Hypothesis**: Showing actual dashboard metrics built by former students improves enrollment sign-ups.
- **Testing Requirement**: Enforce strict responsive aspect ratios.
- **Originality Safeguard**: Simple browser bounds. Do not copy Stripe skewed cards.

---

### 6. Course Faculty (Trainer Bios)

- **Evidence IDs**: `EVI-IIDE-HUB`, `EVI-TOPS-AMD`
- **ASDM-Specific Business Reason**: Reassure students of direct guidance from certified industry trainers (like Love Tyagi).
- **Content Dependency**: Verified trainer bios.
- **Asset Dependency**: Professional trainer headshots.
- **SEO Purpose**: Author rank authority indexing.
- **Conversion Hypothesis**: Real trainers with linked LinkedIn profiles build trust.
- **Testing Requirement**: Formal written approval from trainers is required.
- **Originality Safeguard**: Flat, solid background photo container shapes.

---

### 7. Course Certification

- **Evidence IDs**: `EVI-IIDE-HUB`
- **ASDM-Specific Business Reason**: Display the certificate students receive.
- **Content Dependency**: Signed Skill India partnership.
- **Asset Dependency**: Certificate layout mockup.
- **SEO Purpose**: Verification query indexing.
- **Conversion Hypothesis**: Displaying the physical certificate template increases user trust.
- **Testing Requirement**: Image dimensions set to prevent CLS.
- **Originality Safeguard**: Standard certification display.

---

### 8. Course FAQs & Final counseling CTA

- **Evidence IDs**: `EVI-IIDE-HUB`, `EVI-TOPS-AMD`
- **ASDM-Specific Business Reason**: Capture leads directly at the end of the course description.
- **Content Dependency**: Dynamic center dropdown.
- **Asset Dependency**: None.
- **SEO Purpose**: Local SEO query capture.
- **Conversion Hypothesis**: Gated brochure form modal coupled with a sticky header download button increases conversions.
- **Testing Requirement**: Forms must be fully keyboard accessible.
- **Originality Safeguard**: Minimal clean layout.
