# Homepage Design Rules

Status: `PHASE 7 LOCKED`
Last updated: 2026-08-01

## Permanent Rules

- The homepage is built section by section.
- The registered section order and names may only be changed with explicit owner approval.
- Each section must preserve the ASDM Signature Design System.
- Approved global header and footer are not redesigned during section work.
- Do not add unverified statistics, placements, rankings, accreditations, packages, student counts, government claims, or certification claims.
- Do not copy IIDE, TOPS, or any reference layout, copy, colors, imagery, source code, testimonial arrangement, or CTA pattern.
- Use local approved assets from `public/assets/` whenever possible.
- Use external stock only as a clearly documented temporary asset when no credible local visual exists.
- Avoid heavy gradients, glassmorphism, overloaded card collages, fake browser mockups, logo marquees, and unverified proof widgets.

## Section Completion Rules

- A section is `COMPLETE` only after implementation, screenshots, validation, documentation, and owner-facing review notes exist.
- `APPROVED` sections may receive defect fixes, but not visual redesigns, without explicit owner approval.
- Future homepage sections must start from the registry and dependencies files before design begins.
